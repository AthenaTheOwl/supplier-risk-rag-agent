# Eval Methodology

The eval runner is `python -m src.evals.runner`.

## Suites

- `retrieval_quality.yaml`: query to expected accession or CIK pairs. Metrics:
  recall at 5 and MRR. Gate: recall at 5 >= 0.70.
- `citation_faithfulness.yaml`: supported questions that must return verified
  citation spans. Gate: faithfulness >= 0.95.
- `supplier_risk_questions.yaml`: realistic supplier-risk questions scored by
  a deterministic local regression proxy. Gate: answer quality >= 0.80.
- `refusal_cases.yaml`: out-of-scope or unsupported questions. Gate: refusal
  precision >= 0.85.

## Why deterministic evaluators

CI must pass without real API keys. The local evaluators test the behavior that
can be verified deterministically: retrieval hits, citation span existence,
refusal behavior, and regression coverage. Live LLM judging can be added later
for local or scheduled runs with a controlled test budget.

## Reports

The baseline report at `reports/baseline_eval_report.html` is generated by:

```powershell
python -m uv run python -m src.evals.runner --suite all --report reports/baseline_eval_report.html
```
